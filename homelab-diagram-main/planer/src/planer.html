Bedienung

Ziehen einer Karte verschiebt sie (Raster 8 px, blaue Hilfslinien richten aus).

Kabel: vom kleinen Kreis an der Karte oder von einer Buchse auf eine andere Karte ziehen.

Doppelklick auf ein Kabel setzt einen Wegpunkt.

Shift + Klick oder Rahmen: mehrere auswählen.

Leere Fläche ziehen = verschieben, Mausrad/zwei Finger = zoomen.

Pfeiltasten bewegen, Entf löscht, Strg+Z rückgängig.

Speichern: automatisch im Browser. Für das Diagramm-Tool „YAML speichern“, dann python3 build.py --lab=datei.yaml.
